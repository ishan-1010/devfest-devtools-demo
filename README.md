# Campus Event Finder (talk demo)

A small page with deliberate bugs, made for a talk on Chrome DevTools at DevFest Jalandhar 2026.

- `/` the page where typing in search feels slow
- `/broken/` the page where nothing loads (bug 1)
- `/stage2/` the page that shows a JSON error (bug 2)
- `/fixed/` all three problems fixed

The events are fake and generated.
